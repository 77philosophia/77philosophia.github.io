RSSM的组成

在 RSSM（Recurrent State Space Model，例如在 Dreamer 系列中）中，当我们谈论环境的隐状态（Latent State / Hidden Information）*时，它并不是单一的一个向量，而是由*确定性部分 \(h_t\) 和 随机性部分 \(z_t\)（在部分文献中也记为 \(s_t\)）共同组成的复合状态：

\[s_t = (h_t, z_t)\]

  • 确定性的状态h_t(GRU hidden),用来捕捉暂时的依赖，也就是memory

  • 随机的状态z_t(categorical):捕捉当前状态的不确定性

  • 主要的operations:

    • Observe(): h_t, z_t = f(h_{t-1}, z_{t-1}, a_{t-1}, obs_t) --使用了真实的observation

    • Imagine(): h_t, z^t=f(h{t-1}, z_{t-1}, a_{t-1}). -----no observation(纯想象)，也是dreamerv3的actor-critic工作的部分

训练

actor-critic

dreamerv3会先在world model里面预热几个episodes之后再在actor-ctric框架中训练agent的动作。

我们主要关注actor-critic的逻辑。

Actor(latent) -> action -> imagine_step -> next_latent ->reward

特别注意：actor_loss的计算用的是normalized之后的lambda_Returns值。

正如前面讨论的，传统的无模型强化学习（如 PPO）由于环境不可导，必须使用 Score Function（\(\text{Advantage} \times \nabla \log \pi\)） 来估计梯度。

但在拥有可导世界模型的算法（如 DreamerV3）中：

  • 策略（Actor）的更新往往不直接使用传统的 Score Function，而是直接利用 Pathwise Derivative（路径导数 / 重参数化技巧）。

    1. Score Function 的数学本质：似然比技巧 (Likelihood Ratio Trick)

    • 原理：利用对数导数恒等式 \(\nabla_\theta p_\theta(x) = p_\theta(x) \nabla_\theta \log p_\theta(x)\)。
    • 作用：它允许我们在函数 \(f(x)\) 不可导、未知或者包含黑盒环境的情况下，仅仅通过对概率分布 \(p_\theta(x)\) 进行采样和求对数梯度，就能无偏地估计出期望的梯度。它是无模型强化学习（如 REINFORCE、PPO）和变分推断（如标准的 VAE）的基石。

    2. Pathwise Derivative 的数学本质：重参数化与链式法则 (Reparameterization & Chain Rule)

    • 原理：如果随机变量 \(x\) 可以表示为参数 \(\theta\) 和外部独立噪声 \(\epsilon\) 的可导确定性映射 \(x = g_\theta(\epsilon)\)，那么求导时可以直接穿透期望符号：

      \[\nabla_\theta \mathbb{E}[f(x)] = \mathbb{E}\left[ \frac{\partial f}{\partial x} \frac{\partial g_\theta}{\partial \theta} \right]\]

    • 在世界模型（如 DreamerV3）中的应用：整个世界模型（状态转移方程、观察模型）和策略网络（Actor）共同构成了一个巨大的、参数化的可微计算图。策略生成的动作 \(a_t\) 输入给可微的世界模型得到下一状态 \(s_{t+1}\)，再结合价值函数（Critic），最终的累积回报 \(J\) 对策略参数 \(\theta\) 求导时，不需要做统计意义上的似然比估计，而是直接通过时间轴（Backpropagation Through Time, BPTT）一路反向传播链式法则。

总结wm

总而言之，对wm建模，训练想想未来horizon步数的能力，会估计未来的observation, rewards和continue.

对wm先warm up训练一段时间。

对actor-critic来说，在wm训练之后，用想象horizon步数的latents去估计采样action和对应的action_entropy，去经过mlp估计value,然后计算gae的值
